Modelling Assumptions
AssumptionMeaning
Frictionless pulleysThe pulleys change the direction of the string without adding any resistive force — tension is the same throughout each string.
Inextensible stringsThe strings do not stretch, so the total length of each string remains constant as the system moves.
Light stringsThe mass of the strings is negligible, so they contribute no weight to the system.
Particle modelEach weight is treated as a point mass — its size and shape are ignored.
Static equilibriumThe system is at rest with zero acceleration; all forces on the central box are balanced.
Gravity uniformg = 9.81 m s⁻² acts vertically downward on all masses.
